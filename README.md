# Gemini AI Studio - টেক্সট টু অডিও জেনারেটর ওয়েবসাইট 🎙️

এই প্রজেক্টটি দিয়ে আপনি বড় যেকোনো টেক্সট দিলে ওয়েবসাইটটি স্বয়ংক্রিয়ভাবে প্রতি **১০ লাইনে** আলাদা আলাদা বক্সে ভাগ করে দেবে। প্রতিটি বক্সের সাথে **"অডিও জেনারেট"** এবং **"ডাউনলোড"** বাটন রয়েছে।

এটি সরাসরি **Google AI Studio-র Free API** (Gemini 2.0 Flash Audio) ব্যবহার করে অডিও তৈরি করে।

---

## 🌟 প্রধান ফিচারসমূহ:
1. **অটো ১০ লাইন স্প্লিট:** আপনি টেক্সট পেস্ট করার সাথে সাথে স্বয়ংক্রিয়ভাবে প্রতি ১০ লাইন করে আলাদা বক্সে চলে যাবে।
2. **এডিটেবল বক্স:** অডিও জেনারেট করার আগে আপনি চাইলে প্রতিটি বক্সের লেখা এডিট বা পরিবর্তন করতে পারবেন।
3. **আলাদা অডিও জেনারেশন:** প্রতিটি বক্সের জন্য আলাদাভাবে অডিও তৈরি করার সুবিধা।
4. **ব্রাউজার অডিও প্লেয়ার:** অডিও তৈরি হলে ব্রাউজারেই সরাসরি শুনে নেওয়ার সুবিধা।
5. **ওয়ান-ক্লিক ডাউনলোড:** প্রতিটি অডিও ফাইল `.wav` ফরম্যাটে সহজে ডাউনলোড করা যায়।
6. **সবগুলো একসাথে জেনারেট ও ZIP ডাউনলোড:** এক ক্লিকে সবগুলো বক্সের অডিও স্বয়ংক্রিয়ভাবে তৈরি হবে এবং সব ফাইল একসাথে একটি ZIP ফাইলে ডাউনলোড হবে।
7. **১০০% ফ্রি ও নো-ইনস্টল:** পাইথনের বিল্ট-ইন লাইব্রেরি ব্যবহার করা হয়েছে, কোনো অতিরিক্ত `pip install` করার প্রয়োজন নেই!

## 🚀 কীভাবে চালাবেন (How to Run):

### সহজ পদ্ধতি (Windows Double Click):
* ফোল্ডারে থাকা **`run.bat`** ফাইলে ডাবল-ক্লিক করুন। 
* স্বয়ংক্রিয়ভাবে সার্ভার চালু হয়ে ব্রাউজারে `http://localhost:5000` খুলে যাবে!

### টার্মিনাল বা কমান্ড প্রম্পট থেকে:
```bash
python server.py
```
এরপর ব্রাউজারে যান: `http://localhost:5000`

## 🔑 গুগল এআই স্টুডিও API Key পাওয়ার নিয়ম:
1. [Google AI Studio](https://aistudio.google.com/app/apikey) এ যান।
2. আপনার গুগল একাউন্ট দিয়ে সাইন-ইন করে **"Create API key"** বাটনে ক্লিক করুন।
3. তৈরি হওয়া ফ্রি API Key-টি কপি করুন।
4. আমাদের ওয়েবসাইটে উপরের ডানপাশে **"API Key সেট করুন"** বাটনে ক্লিক করে পেস্ট করে **Save** করুন।
5. এটি আপনার ব্রাউজারে নিরাপদে সংরক্ষিত থাকবে, বারবার দিতে হবে না।
